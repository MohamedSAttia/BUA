# النظام المتكامل لإدارة قسم اللغة الإنجليزية — جامعة الباحة (v6.1 — نسخة Vercel)

إعداد وفكرة وتصميم: د. خالد البلوي — جميع الحقوق محفوظة ©

## محتوى المشروع
| الملف | الوظيفة |
|---|---|
| `index.html` | واجهة النظام كاملة |
| `api/auth.js` | الدخول بكلمات مرور مشفّرة، تغيير كلمة المرور، كلمات المرور المؤقتة |
| `api/db.js` | قاعدة البيانات المشتركة (تحديث كل 6 ثوانٍ بين الأجهزة) |
| `api/upload.js` · `api/file.js` | رفع الملفات وعرضها (مستندات الطلبات، ملفات المقررات، الأرشيف) |
| `api/ai.js` | الذكاء الاصطناعي عبر Vercel AI Gateway |
| `api/cron.js` | مهام يومية على الخادم: التصعيد الآلي، تنبيهات تقارير الرسائل، ملخص بريدي |
| `vercel.json` | الإعدادات والمهمة المجدولة اليومية |

## خطوات التشغيل على Vercel (مرة واحدة)
1. **ارفع الملفات** إلى مستودع GitHub المربوط بمشروع Vercel (مثلاً `BUA`): كل الملفات والمجلد `api` كما هي، واحذف ملف HTML القديم.
   ستُنشر نسخة جديدة تلقائياً.
2. **أنشئ مخزن الملفات والبيانات:** من مشروع Vercel ← Storage ← Create ← **Blob** (اختر Private) ← Connect to project.
   يُضاف المتغير `BLOB_READ_WRITE_TOKEN` تلقائياً.
3. **أضف متغيرات البيئة** من Settings ← Environment Variables:
   - `ADMIN_PASSWORD`: كلمة مرور الإعداد الأولى لحساب رئيس القسم (`head`). يُطلب تغييرها عند أول دخول.
   - `AUTH_SECRET`: نص عشوائي طويل (40 حرفاً أو أكثر) لتوقيع جلسات الدخول.
   - `CRON_SECRET`: نص عشوائي لحماية المهمة اليومية.
4. **أعد النشر** (Deployments ← Redeploy) لتفعيل المتغيرات.
5. **ادخل** باسم المستخدم `head` وكلمة مرور الإعداد، ثم غيّرها.
   بعدها افتح **الإعدادات** واستورد الأعضاء والطلاب من Excel، وأنشئ لكل حساب كلمة مرور مؤقتة وسلّمها لصاحبه.

## إضافات اختيارية
- **قاعدة بيانات Postgres (للاستخدام الواسع):** Storage ← Create ← **Neon** ← Connect.
  يتحول النظام تلقائياً للعمل على Postgres عند وجود `DATABASE_URL`.
- **الذكاء الاصطناعي:** يعمل تلقائياً على Vercel عبر AI Gateway (تأكد من تفعيل AI Gateway ورصيده في لوحة الفريق).
  يمكن تغيير النموذج بالمتغير `AI_MODEL` (الافتراضي `anthropic/claude-sonnet-5.5`).
  عند عدم توفره، تعمل محركات القواعد المحلية بدون انقطاع.
- **البريد الإلكتروني:** أضف `RESEND_API_KEY` (من resend.com) و`MAIL_FROM` ليصل لرئيس القسم ملخص يومي بالتنبيهات.

## ملاحظات
- لا تضع أي كلمة مرور أو مفتاح داخل الملفات، بل في متغيرات البيئة فقط.
- حجم الملف الواحد المرفوع حتى 4 م.ب.
- زر «تصفّح نسخة العرض التجريبية» في شاشة الدخول يفتح نسخة ببيانات تجريبية محلية لا تمس البيانات الحقيقية.
- للتجربة على جهازك: `npm install` ثم `ADMIN_PASSWORD=xxx npm run dev` وافتح http://localhost:3000
